# [ISSUE-38] Vista de carpeta estilo Google Drive (nodos cuadrados, carpetas primero)

- **Épica:** web_closure_fase3
- **Scope:** web.app
- **Estado:** pendiente
- **Depende de:** 3.1, 3.5 (explorador consolidado)
- **Conflictos de archivos:** `web/app/src/pages/NodeView/index.jsx`, `web/app/src/features/node/ui/NodeCard.jsx`, `web/app/src/features/node/ui/DocCard.jsx`
- **Commit sugerido:** `feat(explorer): drive-like folder view`
- **Referencias:** `../proposal/plan-cierre-cliente-web.md`, `../frontend/canonical-flows.md`

## Objetivo / alcance

Rediseñar la vista de carpeta para que se parezca a Google Drive:
- Cada nodo (carpeta o archivo) se muestra como un cuadrado (grid compacto), no como tarjeta horizontal.
- Carpetas y archivos se muestran juntos en un mismo grid, aunque **las carpetas siempre primero**.
- Icono + nombre truncado + acciones al hover.
- Mantener gating por hijo (`access_level`) y metadata real (`doc`).

## Requerimientos

- No romper navegación ni flujos 2.x.
- Responsive (grid auto-fill).
- Accesibilidad básica (foco, teclado).

## Archivos afectados

- `web/app/src/pages/NodeView/index.jsx`
- `web/app/src/features/node/ui/NodeCard.jsx`
- `web/app/src/features/node/ui/DocCard.jsx`
- `web/app/src/features/node/ui/NodeList.jsx` (si se reutiliza)

## Criterios de aceptación

- [ ] Nodos renderizados como cuadrados en grid.
- [ ] Carpetas primero, luego archivos, dentro del mismo grid.
- [ ] Acciones (editar/borrar/descargar) accesibles al hover/foco.
- [ ] Degradación si `doc` vacío.
- [ ] Build y lint limpios.

## Fuera de alcance

- Drag & drop, selección múltiple, vistas de lista alternativa (futuro).

## Prompt para agente ejecutor

> "Rediseña NodeView para mostrar carpetas y archivos juntos en un grid de cuadrados, carpetas primero. Reutiliza NodeCard/DocCard adaptándolos a formato cuadrado. Mantén gating por access_level y metadata de doc. No cambies flujos existentes."
